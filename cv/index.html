How to use

  1. Choose a template and press Full Preview / Edit.
  2. Press Edit Mode, then double-click a text area on desktop or tap it on mobile.
  3. Finish editing and press Download PNG for an image or Download A4 PDF for printing.
  4. Check all names, dates, contact details, qualifications, and work history before using the document.

Privacy note: this single-file demo processes edits in your browser. It does not provide secure payment verification or server-side PIN protection. Never place passport numbers or other sensitive information in a public page.
